# Naik.dev

An original, dependency-free personal website for `www.naik.dev`.

The first version is intentionally lightweight: a live London clock, a small
project index, an About section, responsive layouts, and light/dark themes. It
provides a visual and technical foundation while the final content is decided.

## Run locally

```sh
python3 -m http.server 8099
```

Open `http://localhost:8099`.

## Files

- `index.html` — page structure and initial content
- `styles.css` — responsive visual system
- `app.js` — London clock and theme preference
- `favicon.svg` — local site icon

The site has no build step, package dependencies, analytics, tracking, or
external runtime assets.

## Current domain state

As of 18 September 2026, `www.naik.dev` serves an older GitHub Pages website.
This new project has not been published and does not change the current domain.
